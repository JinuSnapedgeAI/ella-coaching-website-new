# Ella | Confidence & Mindset Coach

Website for Ella's confidence and mindset coaching practice. Built with Next.js.

- `npm run dev` – start locally on http://localhost:3000
- `npm run build && npm start` – production build
- Content: `data/coach.json` (program, stories, packages) and `components/homes/home-1/`
- Set `NEXT_PUBLIC_SITE_URL` to the live domain for correct canonical/sitemap URLs.
